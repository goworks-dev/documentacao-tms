# Documentação de Uso da API

Essa é a documentão de funcionalidades da API do AverbGo.

Por meio dessa API, o TMS deverá enviar todos os XMLs emitidos pelo segurado. Devem estar no padrão SEFAZ e protocolados.  
MDF-e e seus eventos, CTe e seus eventos, NFe e seus eventos.

Caso tenham necessidade de envio do XML de outros documentos, favor antes consultar o suporte AverbGo: sc@averbgo.com.br.

## End-point da API

- Endereço da API: **`https://api.averbgo.com.br`**
